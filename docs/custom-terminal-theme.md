# 主题与配色方案

“配色方案”页列出 `theme.json` 中每套方案，仅负责添加、编辑、删除，不改变正在使用的主题。“添加配色方案”会打开预填当前颜色的 JSON 编辑弹窗。文件至少保留一套方案；保存前校验完整配色，无效输入不会替换当前方案。“外观”页中的主题设置分别选择明色和暗色配色方案；白天或夜间模式使用对应槽位，跟随系统则按 Windows 明暗设置切换。工作区和终端使用当前方案。明色方案的输入框、下拉框触发区和弹出菜单使用同一基础表面色，菜单以边缘阴影区分层级；暗色方案的弹出菜单沿用侧边栏面板色。遮罩随当前明暗方案更新。这些界面颜色从现有终端背景、前景和光标色推导，不更改 ANSI 调色板或终端颜色报告。

侧边栏透明度独立保存在 `workspace.json`，没有保存值时默认不透明；侧边栏显示且不透明度低于 100% 时使用 Windows 毛玻璃窗口背景。背景透明度仍作用于内容区；系统的模糊效果是窗口级别，若内容区也透明，在侧边栏启用毛玻璃时该区域也会显示模糊。

所有主题保存在一个 `theme.json` 文件中。启动时文件不存在则从内置模板创建，模板包含原有 17 套方案，以及 Codex Light/Dark 和 VS Code Light/Dark Modern 四套新方案。旧版文件升级到版本 2 时只追加缺失的内置方案，不覆盖同名方案的用户修改；若存在旧版 `terminal-theme.json`，会将它追加到模板中。Windows 默认路径是 `%APPDATA%\tshell\theme.json`；设置了 `TSHELL_DATA_DIR` 时，文件位于该目录下。外部编辑文件后，可用页面右上角的刷新按钮重新加载。

文件包含 `version` 和 `themes`。每个 `themes` 条目包含稳定的 `id`、显示名称 `name`、`foreground`、`background`、`cursor`、`selection` 和 `ansi`。颜色格式必须是 `#RRGGBB`。`ansi` 恰好 16 项：黑、红、绿、黄、蓝、品红、青、白，然后是对应的 8 个亮色。`id` 只使用小写英文字母、数字和连字符。两个槽位分别以 `light_theme`、`dark_theme` 保存在 `workspace.json`。旧版 Codex/VS Code 选择会迁移到对应的明暗方案；旧版单独选择的方案保留在与其亮度相符的槽位，另一槽位采用内置默认方案。自动模式不读取 Windows 强调色。VS Code 基色取自其 Light/Dark Modern 默认主题。
